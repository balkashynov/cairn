# Data provenance and attribution

Cairn's code is MIT licensed. Benchmark corpora, query text and relevance judgments are external research data and are not relicensed by that code license. The downloader records the source revision, URLs and file hashes. Large data and complete local reports are excluded from Git.

## Cohere BEIR embeddings

Source: [CohereLabs/beir-embed-english-v3](https://huggingface.co/datasets/CohereLabs/beir-embed-english-v3), revision `f018922a46a51388348a307ec2fef28019a33026`. The publisher identifies the model as `embed-english-v3.0` and supplies corpus embeddings, query embeddings and relevance judgments. Cairn uses the complete test split of each selected dataset. This is not a measurement of Embed 5.

Original benchmark framework: [BEIR](https://github.com/beir-cellar/beir). BEIR's code license is distinct from individual dataset licenses.

- **SciFact:** [AllenAI SciFact](https://github.com/allenai/scifact), Wadden et al., *Fact or Fiction: Verifying Scientific Claims* (EMNLP 2020). [Original data license](https://github.com/allenai/scifact/blob/master/LICENSE.md): claims and evidence annotations under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); abstracts are drawn from [S2ORC](https://github.com/allenai/s2orc) under [ODC-By 1.0](https://opendatacommons.org/licenses/by/1-0/). Report excerpts are truncated for display, and rankings/counters are generated by Cairn. The original authors retain credit for the text.
- **FiQA:** [FiQA challenge](https://sites.google.com/view/fiqa/) and [BEIR's FiQA distribution](https://huggingface.co/datasets/BeIR/fiqa), whose dataset card identifies [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Finance question/answer text originates from its contributors.
- **CQADupStack programmers:** [CQADupStack](https://github.com/D1Doris/CQADupStack), Hoogeveen et al., forum question retrieval based on Stack Exchange. The downloader leaves original IDs in the metadata. Follow the original dataset and Stack Exchange attribution requirements when redistributing text. The published numeric benchmark does not redistribute this corpus.

The portable demo uses a small set of attributed SciFact query/abstract excerpts, with source IDs retained. Numeric full-query results contain IDs, scores, timing and work counters. Regenerate full text reports locally from the cited sources.

## Historical Cohere Wikipedia benchmark

Source: [Qdrant vector-db-benchmark](https://github.com/qdrant/vector-db-benchmark/blob/acedefda700e2b2895164e2338893d945d6d3c1e/datasets/datasets.json). The downloader records archive and/or extracted-file checksums. The archive supplies vectors, queries and neighbor lists but does not establish the exact model version or natural-language query construction. Cairn recomputes its own reference rankings; it does not claim these are Embed 5 or a current model relevance benchmark. Wikipedia-derived text is not included in the published numeric results.
