What these measurements do and do not establish

Exactness means the same ordered top-k as an exhaustive dot product over stored normalized float32 vectors, accumulated in float64, with document ID breaking ties. It does not mean every result is relevant. Relevance nDCG, when supplied, uses the dataset's judgments separately.

Certified pruning scans every eligible int8 code. It retains full vectors on disk, so total storage is larger than float32 alone. Memory mapping uses the operating system's page cache; the fraction of full vectors scored is not a claim about physical reads or peak resident memory. Nearly tied vectors can force an exhaustive fallback.

These are recorded benchmark queries and measurements, replayed locally. The page does not embed new text or perform a live search. Use the CLI or Python client on your own corpus.
